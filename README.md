# Medical Booking

**Описание:** Информационная система для онлайн-записи пациентов на приём к врачам. Система позволяет пациентам находить специалистов, бронировать свободные слоты и управлять записями, а врачам — настраивать расписание и управлять заявками.

**Статус:** В разработке (учебный проект). Версия: 1.0.

## Установка
Для развёртывания проекта на локальном компьютере необходимо склонировать репозиторий командой `git clone`. Затем создайте виртуальное окружение Python и активируйте его. Установите зависимости командой `pip install -r requirements.txt`. После этого настройте подключение к базе данных Microsoft SQL Server в файле `.env`.

## Использование
Для запуска сервера разработки выполните команду `python manage.py runserver`. После этого приложение будет доступно по адресу `http://127.0.0.1:8000/`. Для работы с базой данных примените миграции командой `python manage.py migrate` перед первым запуском.

## Конфигурация
В файле `.env` необходимо указать следующие переменные окружения: `DB_HOST` (адрес сервера), `DB_NAME` (имя базы данных), `DB_USER` (имя пользователя) и `DB_PASSWORD` (пароль). Также в файле `settings.py` можно изменить параметры `DEBUG` и `ALLOWED_HOSTS` для развёртывания на сервере.
